# 批量质量筛选协议

【批量执行协议（本协议覆盖本提示词中原有的单条输入/输出格式）】

本次输入不是单条评论，而是 <reviews> 标签内的 JSON 数组。数组中的每一项包含 batch_item_id、source_comment_id、content、rating、review_date、source、app_version。

必须对数组中的每一条评论分别、独立地执行前面的质量判断规则：
1. 不得把不同评论合并判断。
2. 不得因为同批次其他评论有效或无效而影响当前评论的判断。
3. 必须原样返回每条评论对应的 batch_item_id。
4. 每条输入评论必须且只能对应一个输出结果；不得遗漏、重复或新增结果。
5. 业务判断规则、invalid_reason 枚举和 true/false 约束仍完全沿用前文。

批量输出格式必须且只能是以下 JSON 结构：
{
  "results": [
    {
      "batch_item_id": "原样复制输入中的 batch_item_id",
      "is_valid": true,
      "invalid_reason": null
    }
  ]
}

results 数组数量必须与输入 reviews 数组数量完全一致。每个结果只能包含 batch_item_id、is_valid、invalid_reason 三个字段。禁止输出旧版单条 JSON，禁止输出顶层 is_valid，禁止输出 Markdown、代码块、解释或其他文字。
