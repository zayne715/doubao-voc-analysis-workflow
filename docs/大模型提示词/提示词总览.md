## 维护约定

1. n8n 工作流中的提示词是运行时来源；这些 Markdown 是便于审阅、版本管理和协作的文档副本。
2. 修改提示词后，应同时更新对应 Markdown，并验证模型输出解析与业务校验。
3. JSON 字段名保持英文是接口契约；面向用户的报告正文应使用简体中文。
4. 不把 API Key、个人凭据或运行时数据写进提示词文档。
